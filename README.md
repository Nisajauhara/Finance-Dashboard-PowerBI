# 📊 Finance Dashboard | Power BI

## 📖 Project Overview

This project is an interactive Finance Dashboard developed in **Power BI** to transform raw financial data into meaningful business insights.

The objective of this dashboard is to help users analyze financial performance through interactive visualizations, making it easier to identify trends, monitor key metrics, and support better business decisions.

---

## 🎯 Project Objectives

- Clean and prepare raw financial data.
- Build accurate financial measures and calculations.
- Create relationships between multiple tables.
- Design an interactive dashboard for better user experience.
- Present financial insights in a clear and meaningful way.

---

## 🛠 Tools Used

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)

---

## 🚀 Challenges Faced

During this project, I worked on several real-world data challenges, including:

- Data Cleaning to improve data quality and consistency.
- Creating DAX Measures for important financial metrics.
- Building Relationships between multiple tables.
- Designing Interactive Buttons and Navigation.
- Creating meaningful visualizations for business users.

---

## 💡 Solution Approach

To overcome these challenges, I:

- Carefully analyzed the dataset.
- Created additional tables where required.
- Developed custom DAX measures.
- Established proper table relationships.
- Designed an interactive dashboard with user-friendly navigation.
